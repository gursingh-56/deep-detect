Technique Used

The Deepfake Detection System employs a sophisticated deep learning architecture. It primarily utilizes a **ResNeXt50 Convolutional Neural Network (CNN)** for robust feature extraction from individual video frames. These spatial features are then fed into a **Long Short-Term Memory (LSTM) network**, which analyzes temporal inconsistencies and patterns across a sequence of frames. This spatio-temporal analysis allows the model to identify subtle artifacts often missed by frame-only detection methods, crucial for distinguishing between real and synthetically generated content.

The model is trained on diverse datasets of both real and deepfake videos to learn complex discriminative features.
